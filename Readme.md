Project HTML Lanjutan
Deskripsi

Project ini merupakan latihan HTML Lanjutan yang dibuat untuk mempelajari dan menerapkan berbagai elemen HTML dalam pembuatan halaman web sederhana.

Materi yang Dipelajari

Beberapa materi yang diterapkan dalam project ini meliputi:

Tabel data mahasiswa
Tabel nilai praktikum
Form registrasi mahasiswa
Input teks, email, password, dan tanggal
Radio button
Checkbox
Semantic HTML
Navigasi halaman
Biodata mahasiswa
Audio
Video

Fitur
1. Data Mahasiswa

Menampilkan informasi mahasiswa dalam bentuk tabel, seperti NIM, nama, dan program studi.

2. Nilai Praktikum

Menampilkan daftar nilai praktikum mahasiswa dan rata-rata nilai.

3. Form Registrasi

Form yang digunakan untuk memasukkan:

Nama lengkap
Email
Password
Tanggal lahir
Jenis kelamin
Keahlian
4. Portal Mahasiswa

Menggunakan semantic HTML seperti:

<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
5. Multimedia

Project juga menggunakan elemen HTML untuk menampilkan:

Audio
Video
Teknologi yang Digunakan
HTML5
Visual Studio Code
Google Chrome
Cara Menjalankan
Download atau clone repository.
Buka folder project menggunakan Visual Studio Code.
Pastikan file audio dan video berada di folder media.
Buka file index.html.
Jalankan menggunakan browser seperti Google Chrome.
Tujuan

Tujuan dari project ini adalah untuk memahami dasar-dasar HTML lanjutan serta mampu membuat halaman web sederhana yang memiliki tabel, form, navigasi, semantic HTML, dan multimedia.
